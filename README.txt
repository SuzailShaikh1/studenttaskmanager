# Daymark — React Student Task Manager

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown in the terminal (usually http://localhost:5173).

## Main files
- `src/App.jsx`: React components, state, task logic, filters, sorting, and modal form.
- `src/main.jsx`: React entry point.
- `src/style.css`: responsive UI styles.
- `index.html`: Vite page shell.

Tasks are saved in browser Local Storage. Sample tasks appear on first launch.
